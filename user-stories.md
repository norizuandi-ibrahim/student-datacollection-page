# User Stories

1. As a lecturer, I want to upload student academic data, so that the AI system can analyse student performance and predict their academic risk levels.
2. As an academic advisor, I want to view a dashboard showing students with low, moderate, and high academic risk, so that I can identify students who need additional academic support.
3. As a lecturer, I want the system to recommend suitable support activities and generate academic risk reports, so that I can help struggling students improve their academic performance.
4. As a lecturer, I want to track changes in students' academic performance over time, so that I can evaluate whether the academic support provided is helping them improve their results.
